# spec/pb/signer/

> Generated Go bindings for the `Signer` gRPC service — DO NOT EDIT; regenerate from the proto instead.

## What this is
These files are produced by `protoc` (via `scripts/gen-proto.sh`) from `../../signer/signer.proto`. They are the Go package `signer` that `signerserver/` imports as `pb` to implement and register the service. Every file here is machine-generated and carries a `Code generated ... DO NOT EDIT.` header — treat them as build artifacts, not editable source.

## Contents
- `signer.pb.go` — generated by `protoc-gen-go`; message structs (`PublicKeyResponse`, `SignRequest`, etc.) plus marshal/reflect glue
- `signer_grpc.pb.go` — generated by `protoc-gen-go-grpc`; `SignerClient`, `SignerServer`, `UnimplementedSignerServer`, and `RegisterSignerServer`

## How it works
`signerserver/signerserver.go` embeds `pb.UnimplementedSignerServer`, implements the three RPC methods against `*pb` request/response types, and calls `pb.RegisterSignerServer(grpcSrv, srv)` to attach the handler to a gRPC server. The full method names (e.g. `/signer.Signer/Sign`) and version-compatibility asserts (`protoimpl.EnforceVersion`, `grpc.SupportPackageIsVersion9`) are baked into the generated code, so the bindings are tied to specific `protoc`/plugin/runtime versions. Headers record the exact tool versions used (protoc v7.35.0, protoc-gen-go v1.36.11, protoc-gen-go-grpc v1.6.2).

## Troubleshooting
- You edited a `.pb.go` by hand → changes are lost on regen and break the "do not edit" contract → make the change in `../../signer/signer.proto` and run `./scripts/gen-proto.sh`.
- `EnforceVersion` / `SupportPackageIsVersion9` compile error → generated code is older/newer than the `google.golang.org/protobuf` or `google.golang.org/grpc` in `go.mod` → reinstall the generator plugins and regenerate, then `go mod tidy`.
- `undefined: pb.RegisterSignerServer` or a missing message field → bindings out of sync with the proto → regenerate; commit `signer.pb.go` and `signer_grpc.pb.go` together.
- Package import fails → wrong path → import `github.com/ava-labs/avalanche-deploy/tools/remote-signer/spec/pb/signer` (set by `go_package` in the proto).
